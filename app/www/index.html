本应用 FPK更新 v— —
—
升级走飞牛应用中心官方通道，保数据、不重装。被更新的应用会短暂重启。

设置

只有列在这里的应用会被显示和操作。加一个应用只要填它的 GitHub 仓库 （owner/name 或完整链接）—— 应用名、显示名、版本都会自动识别 （读 fpk 自身的 manifest，所以任何仓库都能用，不需要改仓库，也不需要重装本应用）。 也可以填 fpk 直链。

本应用自己（FPK更新）不在这里 —— 它在上方独立的「本应用」区块里更新。 「全部更新」也不会带上它（更新自己会重启本应用，会把队列里后面的应用一起打断）。

添加应用仓库

输入 GitHub 仓库名（如 owner/name 或完整链接），点「获取版本」后选 更新方式再加进列表：跟随最新（默认，自动跟上游正式版）或 锁定版本（固定用某个 Release，用于回滚或避开有问题的版本）。

本应用自己

        

          自身更新用哪条来源。留空 = 用内置默认（打包本应用的那个仓库）。改完会自动重查一次。
        

        

          
          
        

      


      
      

        
自动下载

        
        

          只下载，不会自动安装 —— 装不装、什么时候装仍然由你点。
          开了之后新版本的包会在后台悄悄下好，你只要在方便的时候点一下「安装」。
        


        
下载加速

        

          
        

        

          
          
        

        

          
        

        

        

          
        

        

          大文件按段并发下载（1 = 不分段，4 段是默认）。并发只影响速度，不影响结果：
          下完一律过 sha256 校验，对不上直接丢弃。

          到 GitHub 慢可以选加速镜像 —— 走镜像同样要过 sha256，镜像只能提速、改不了内容
          （镜像挂了会自动回落直连）。
        


        
安装包下载目录

        
—

        

          
          
        

        

          
        

        

          点「更新」时会把安装包下载到这里（校验 sha256 后才使用；失败时保留作回滚包，装成功后按上面的清理设置处理）。
          必须是绝对路径，且不能放在应用安装目录（@appcenter）或别的应用的数据目录里。
        


        
安装包清理

        
        

          装成功了这个包就没用了，而它是刚下下来的、随时能从 Release 再取。
          只在核验通过后才删（版本确实变了、应用目录还在）；失败或装完起不来的情况一律保留，
          因为它此时是回滚包。
        

        
        
可清理：—

        

          
          
        

        

          只清理本应用自己下载过的包（下载完会记一笔台账，装完/清完就销账）。
          下载目录里你自己归档、或别的脚本放进来的 fpk 一个都不会动 ——
          那可能是你的回滚包。清理前会先列出清单让你确认。
        

      


      
      

        
主题

        

          
          
          
        

        

          默认「跟随系统」—— 手机/电脑切到暗色，这里也跟着变。
          也可以强制固定成浅色或深色。选择会记在本机，下次打开还是它。
